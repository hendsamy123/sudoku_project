# Data dictionary (P7 – Handwritten Sudoku Reader and Solver)

## Real data (MNIST, http://yann.lecun.com/exdb/mnist/)
| Field | Type | Real/Generated | Notes |
|---|---|---|---|
| `x_train`, `x_val`, `x_test` | uint8 (N,28,28), stored flat as 784 → float32 in [0,1] at load | **Real** | Handwritten digits, centred. Digit 0 removed. |
| `y_*` | int 1..9 | **Real** | Original MNIST labels. |
| split | 44,077 train / 10,000 val / 9,020 test | Generated by `make_data.py` | Val = random 10,000 of the ORIGINAL training set (seed 7). The original test set is untouched. |

## Generated data (`data/puzzles.py`, always seeded)
| Object | How it is made |
|---|---|
| Full grid | Randomised backtracking with MRV, digits tried in a seeded random order. |
| Puzzle | Cells removed in seeded random order; a removal is kept only if the solution stays **unique** (checked by the CSP counting up to 2 solutions), until `n_givens` (25/30/35) remain. |
| Cell images / mosaic | Each given gets a random 28×28 MNIST **test** image of its digit; blank cells are all-zero images. Mosaic = 9×9 tiling → 252×252. NOT a photo of a real Sudoku. |
| Clean image pool | Test images the network classifies correctly. Used for every non-injected cell, so the only misreads are the injected ones. |
| Hard image pool (injected misreads) | Test images the network misclassifies but whose true digit is within its top-3. `m` randomly chosen given cells get a hard image of their own digit (`m` = 0..4 = "misread level"). |
| Blank-cell detection | Rule, not the network: mean pixel intensity < 0.01. |
| Correction cost | `log p(read digit) − log p(new digit)` (≥ 0 since the read digit is the arg-max). |
| Seeds | `make_data.py`: 7. Network: 0. Experiments: seeds 1–5 (instances) and 1001–1005 (random-correction baseline). Demo: `--seed`. |
